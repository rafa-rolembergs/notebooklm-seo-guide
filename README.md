# Miniguia de SEO com NotebookLM

## Objetivo

Este projeto foi desenvolvido como parte do desafio da DIO para explorar o uso do NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi SEO (Search Engine Optimization), com foco em boas práticas recomendadas pelo Google para aumentar a visibilidade orgânica de sites.

### Objetivos de estudo

* Compreender os fatores que impactam o ranqueamento orgânico.
* Aprender boas práticas de SEO técnico.
* Entender conceitos de EEAT.
* Explorar estratégias para SEO em ambientes de IA generativa.
* Criar um guia de consulta rápida para futuras otimizações.

# Miniguia de Estudo

## Resumo

SEO é o conjunto de técnicas utilizadas para melhorar a visibilidade orgânica de um site nos mecanismos de busca.

Os pilares principais são:

* SEO Técnico
* SEO On Page
* SEO Off Page
* Experiência do Usuário
* EEAT

---

# Glossário

## SEO

Search Engine Optimization.

## Crawling

Processo de descoberta de páginas pelos mecanismos de busca.

## Indexação

Processo de armazenamento das páginas no índice do Google.

## EEAT

Experience, Expertise, Authoritativeness e Trustworthiness.

## Core Web Vitals

Métricas relacionadas à experiência do usuário.
